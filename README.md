# 🏗️ Lohari Fabrication Store

A full-stack e-commerce platform for fabrication stores with AI-powered RAG assistant, Google OAuth2 authentication, and custom drawing module.

---

## 🚀 Tech Stack

- **Frontend:** ReactJS, Tailwind CSS, Vite
- **Backend:** Spring Boot, Java
- **Database:** MySQL
- **Security:** Google OAuth2, JWT
- **AI/ML:** Llama 2.0, Anthropic Claude (RAG)  // Upcoming ................
- **Tools:** Postman, Git, GitHub

---

## ✨ Features

- 🔐 Google OAuth2 Authentication - Secure login with Google
- 🎨 Custom Drawing Module - Design your own products
- 🤖 AI-Powered RAG Assistant - Llama 2.0 + Claude for customer support
- 📱 Responsive Glass-Morph UI - Modern, beautiful design
- 🛒 Product Management - Add, edit, delete products
- 👥 User & Order Management - Complete admin panel
- 📦 Shopping Cart - Add to cart, checkout functionality
